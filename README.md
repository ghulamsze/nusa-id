# nusa-id
NUSA is a mobile-first web super-app built with Vanilla JS (ES Modules) and Tailwind CSS for urban mobility, travel, and digital payments. It unifies ride-hailing (NusaRide, NusaCar), food delivery (NusaFood), logistics (NusaSend), and travel booking (NusaFly, NusaRail, NusaBus, NusaStay) into one seamless platform.
